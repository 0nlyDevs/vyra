# Crédits

## Jeu « Vrai ou fake » en 3D

- **Décor de la rue** (bâtiments, routes, lampadaires, voitures, mobilier urbain) : *City Builder Bits*
  de Kay Lousberg (KayKit), licence CC0 1.0 (domaine public). Fichiers dans `web/public/game/city/`,
  licence d'origine dans `web/public/game/city/LICENSE.txt`.
- **Personnages chibi** (Hasina, Toky et les passants), stands d'indices, tampon : modélisés en code
  par l'équipe (`web/src/features/game3d/`).
- **Effets sonores et ambiance** : synthétisés dans le navigateur avec la Web Audio API
  (`web/src/features/game3d/audio.ts`), aucun fichier audio tiers.
