Scénarios de test.

Des messages comme ceux qui circulent, pour essayer l’extension « Vérifier ici » de bout en bout. Chaque carte dit quoi faire et ce que le panneau doit montrer.

Avant de commencer

  1. La plateforme tourne : docker compose up --build, puis make seed pour les données de démo.
  2. L’extension est chargée depuis extension/ (chrome://extensions, mode développeur), puis rechargée après chaque git pull.
  3. Pour cette page ouverte depuis le disque : dans les détails de l’extension, activer « Autoriser l’accès aux URL de fichier », sinon le clic droit n’y apparaît pas.
  4. Rien n’est envoyé avant le clic sur « Vérifier ce contenu » : vérifier aussi ça à chaque scénario.

Clic droit sur un texte

01

Une rumeur déjà jugée, réécrite

Sélectionner tout le message, clic droit → Vérifier ce texte, puis « Vérifier ce contenu ».

Transféré plusieurs fois ⚠️ La Régie des eaux coupe l'eau 10 jours dans toute la ville dès lundi !! Faites vos réserves, transférez à vos proches.
Attendu
  • Le panneau s’ouvre sur « Texte sélectionné », le message en italique ; la ligne passe à 02.
  • Bloc rouge plein « Déjà jugée par le tribunal » : Contredit, « Dix jours sans eau », la conclusion, « Voir les preuves » (ouvre la page publique de l’affaire).
  • Signes d’alerte : Ton sensationnel (appel à partager, points d’exclamation empilés, émoji d’alarme), puis « Peu de danger apparent ».
  • La ligne finit sur trois coches.
02

Une arnaque au recrutement

Sélectionner le message, clic droit → Vérifier ce texte, puis « Vérifier ce contenu ».

Recrutement officiel : 500 postes à pourvoir au ministère. Envoyez 20 000 Ar de frais de dossier par mobile money avant demain midi, places limitées !
Attendu
  • Bloc en pointillés « Pas encore jugée » : l’affaire existe en démo, mais n’est pas conclue.
  • Ton appuyé (urgence : « avant demain ») et Danger possible si elle circule (se présente comme un texte officiel).
  • « Ouvrir une enquête dans la plateforme » ouvre /cases avec le texte pré-rempli (connexion demandée si besoin).
03

Une alerte qui fait peur

Sélectionner le message, clic droit → Vérifier ce texte, puis « Vérifier ce contenu ».

URGENT : inondation ce matin à Ambohitsoa-Nord, 3 morts, l'école est fermée. La mairie cache la vérité. Partagez vite avant que ce soit supprimé !
Attendu
  • « Pas encore jugée ».
  • Ton sensationnel avec quatre signes (urgence, appel à partager, deux fois « on vous cache la vérité »), chacun avec ses mots en italique.
  • Danger possible si elle circule : peut créer la panique (« inondation », « morts »).
04

Une information calme

Sélectionner le paragraphe, clic droit → Vérifier ce texte, puis « Vérifier ce contenu ».

La JIRAMA rappelle que les travaux de maintenance du réseau prévus samedi matin dans le quartier d'Analakely dureront environ trois heures.

Attendu
  • « Pas encore jugée », Ton neutre et Peu de danger apparent, sans signe relevé.
  • Le panneau ne dit jamais « vrai » : seule une affaire jugée donne un verdict.
05

La même rumeur, sans les mêmes mots

Sélectionner le message, clic droit → Vérifier ce texte, puis « Vérifier ce contenu ».

Les robinets resteront secs une semaine et demie, d'après la compagnie, remplissez vos bidons.
Attendu
  • Sans clé d’IA : « Pas encore jugée » (la comparaison se fait sur les mots, et ils sont tous différents).
  • Avec Gemini (GEMINI_API_KEY dans processing/.env, puis make seed) : la comparaison par le sens peut retrouver « Dix jours sans eau ». C’est le cas qui montre l’IA dans la démo.
06

Trop court

Sélectionner seulement le mot ci-dessous, clic droit → Vérifier ce texte, puis « Vérifier ce contenu ».

Faux !
Attendu
  • Message encadré « Un texte de 10 caractères au moins, ou un lien. », l’étape 02 marquée d’une croix, le bouton à nouveau cliquable.

Clic droit sur une image

09

D’où vient cette photo ?

Ouvrir la page Antananarivo de Wikipédia, clic droit sur sa première photo → Examiner cette image, puis « Chercher sa première publication ».

Attendu
  • Le panneau montre l’image ; le bouton dit « Chercher sa première publication ».
  • « Déjà vue ailleurs ? » avec quatre boutons : Google Lens, TinEye, Yandex Images, Bing. Chacun ouvre la recherche inversée dans un onglet.
  • « Aucun outil ne dit avec certitude si une image est générée par IA. » Rien n’est envoyé à la plateforme.

Dans le panneau

10

Coller un message reçu

Cliquer l’icône de l’extension, « Effacer » si un contenu est affiché, puis coller ce texte dans le champ et « Vérifier ce contenu ».

La Régie des eaux annonce 10 jours de coupure dans toute la ville à partir de lundi. Faites vos réserves !
Attendu
  • « Recherche dans les affaires jugées… » reste affiché pendant la recherche.
  • Même résultat que le scénario 01 : Contredit, « Dix jours sans eau ». Ici, Ton neutre et « Danger possible si elle circule » (peut créer la panique : « coupure »).
  • Coller une adresse https://… au lieu d’un texte la traite comme un lien (scénario 07).
11

La plateforme est arrêtée

Arrêter le web : docker compose stop web. Refaire le scénario 01, puis relancer : docker compose start web.

Attendu
  • Message encadré « Plateforme injoignable à http://localhost:3000… », étape 02 en échec.
  • Après le redémarrage, « Vérifier ce contenu » marche de nouveau sans recharger l’extension.
12

Réglages et thèmes

Cliquer « Réglages » en haut du panneau, garder http://localhost:3000 et « Enregistrer ». Puis passer le système en thème clair, puis sombre.

Attendu
  • « Enregistré : http://localhost:3000 », sans demande de permission (localhost est déjà autorisé). Une autre adresse demande votre accord.
  • Le panneau suit le thème du système : papier et encre en clair, inversés en sombre ; seuls les verdicts sont en couleur.
